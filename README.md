# Azure Cloud Networking

A small Azure environment built to practice network segmentation and access control. It includes two peered virtual networks, each split into public and private subnets, with NSG rules controlling inbound traffic.

## Scope
- Two VNets with bidirectional peering
- Public and private subnets
- NSG inbound rules for ICMP
- VMs with and without internet access
- Entra ID users with MFA enforced
- Storage account hosting a static website
- CPU threshold alert in Azure Monitor
- Monthly cost estimate with the Azure pricing calculator
